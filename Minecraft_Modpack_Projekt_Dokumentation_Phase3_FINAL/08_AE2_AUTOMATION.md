# 08 — AE2 & AUTOMATION

## Zweck

Applied Energistics 2 und Applied Mekanistics als später Automatisierungs-/Logistikschwerpunkt.

## Grundidee

AE2 soll nicht bloß ein früheres Storage-System sein. Der Einstieg soll einen echten Progressionsmeilenstein darstellen.

## AE2

🟢 Rolle:
- zentrale Lagerung
- Logistik
- automatisierte Crafting-/Processing-Ketten
- langfristige Infrastruktur

## Applied Mekanistics

🟢 Rolle:
Verbindung zwischen AE2-Automation und Mekanism-Chemie/Gas-/Processing-Systemen.

## Neue AE2-Stufe: früher Storage-Layer

🔵 **Entscheidung für die Progressionsplanung:** AE2 darf früh nutzbar werden, aber zunächst nur als teure Logistikschicht.

Ziel:
- vorhandene normale Truhen anbinden
- Storage Drawers anbinden
- Items zentral über ein ME-Terminal suchen
- vorhandene Lagerinfrastruktur weiterverwenden
- noch keine vollständige ME-Zell-/Crafting-Automation voraussetzen

### Gewünschter Aufbau

**Bestehendes Lager**
→ Truhen / Storage Drawers
→ teures AE2-Anbindungs-/Netzwerk-Gate
→ ME-Terminal
→ zentrale Suche und Zugriff

Danach erst:

**Storage-Layer**
→ ME Drives / Storage Cells
→ Import/Export
→ Crafting Grid
→ Pattern Provider / Processing
→ Applied Mekanistics

### Balancing-Grundsatz

Der frühe Storage-Layer soll bewusst teuer sein. Die Kosten dürfen mehrere bereits etablierte Progressionspfade berühren, z. B.:

- IE-Materialien / Steel
- Certus Quartz / Fluix
- Redstone
- Glas/Quartz bzw. vergleichbare technische Komponenten
- später ggf. ein kleiner Botania-/Blood-Magic-Anteil für hochwertige Varianten

Die exakten Rezeptkosten werden **erst nach Abschluss der Ressourcen- und Progressionsmatrix** festgelegt.
