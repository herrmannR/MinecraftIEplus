# MinecraftIEplus

Ausbau des Forge-Modpacks „Immersive Engineering+“ (ATLauncher, LAN-Welt mit Freunden) auf **Minecraft 1.20.1** zu einem kohärenten Pack mit Raumfahrt als Hauptziel.

- Einstieg: [docs/00_STATUS.md](docs/00_STATUS.md) (Stand, offene Punkte, Arbeitsplan, welches Dokument gilt)
- Doku: `docs/` (Fachdokumente 00–19, Meilensteinkarte, Erzatlas, Modpfade, Questtexte)
- `kubejs/` und `config-overrides/`: Skripte, Datapack und Configs für die Instanzen
