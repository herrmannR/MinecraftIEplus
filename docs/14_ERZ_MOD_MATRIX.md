## Legende

| Zeichen | Bedeutung |
|---|---|
| ⛏ | wird von dieser Mod **erzeugt** (Worldgen), mit Menge: sehr niedrig / niedrig / mittel / hoch |
| ⚙ | wird nur **verarbeitet** (Erz → Staub/Ingot/Flüssigkeit), nicht verbaut |
| 🔧 | wird in Bauteilen/Maschinen/Werkzeugen **verwendet** |
| ● / ●● / ●●● | Wert in dieser Mod: Nebenrolle / wichtig / zentral bzw. Engpass |
| – | keine Rolle |
| (=) | Soll identisch mit Ist |
| (…) | Soll-Zustand nach unseren Anpassungen |
| R | wird per **Retrogen** in bereits erkundete Chunks nachgeneriert |
| OW / TF / NE | Overworld / Twilight Forest / Nether |

Die Bewertung ●–●●● stützt sich auf die Zahl der Rezepte, die das Material verbauen (Anhang), und auf die Progressionsrolle. Ein Beispiel: Uranium hat bei Mekanism kaum normale Rezepte, ist aber Basis der gesamten Nuklearkette.

## Was sich durch das Soll ändert

1. **Blei:** nur noch IE-Erz. Mekanism-Bleierz wird abgeschaltet; Mekanism nutzt IE-Blei über `forge:ingots/lead`.
2. **Uran:** nur noch Mekanism-Erz. IE-Uranerz wird abgeschaltet. 🔵 Die Mekanism-Menge eventuell erhöhen, weil die zweite Quelle wegfällt.
3. **Zinn:** wird zum Twilight-Forest-Exklusiverz (Option B) und damit zum Gate für Bronze und den Mekanism-Ausbau.
4. **Osmium:** in der Overworld deutlich seltener (aber vorhanden, für den Mekanism-Einstieg), im Twilight Forest häufig.
5. **Aluminium, Nickel, Silber, Blei:** in der Overworld selten, im Twilight Forest häufig.
6. **Retrogen:** alle Erze, die in bereits erkundeten Overworld-Chunks fehlen (Mekanism kam neu dazu).
