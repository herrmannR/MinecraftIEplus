# Questtexte je Mod

Erklärtiefe nach `../19_HILFEBUECHER.md`: **ohne Buch** führen die Texte Schritt für Schritt, **mit Buch** nennen sie Ziel und Fundstelle im Buch und erklären nur, was das Pack ändert.
